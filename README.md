# filum-cnc-pi

Плагин для [Filum](https://github.com/fu1se/filum): фрезерный станок на GRBL под управлением
[cncd](https://github.com/fu1se/cnc-pi) выбирается в приложении как ещё один принтер.

[English below](#english)

```
┌────────────┐  Wi-Fi  ┌──────────────────┐  USB  ┌────────────┐
│ Filum      │ ──────► │ Raspberry Pi     │ ────► │ плата GRBL │
│ + плагин   │  HTTP   │ cncd :8080       │       │   станка   │
└────────────┘         └──────────────────┘       └────────────┘
```

## Что умеет

Через обычный интерфейс Filum:

| Где | Что |
|---|---|
| Главная | Статус станка (Простой, Работа, Пауза, Джог, АВАРИЯ…), задание, прогресс, прошедшее и оставшееся время, кнопки «Пауза», «Продолжить», «Стоп». Если к Pi подключена камера, на главной её поток |
| Управление | Джог XY и Z с шагом 0.01–50 мм, Home (`$H`) |
| Файлы | Файлы G-кода на Pi и запуск задания |
| Консоль | Любые команды GRBL (`G0 X10`, `$$`, `$X`…) |

И свой раздел «ЧПУ» на вкладке «Управление»:
- **Разблок. $X** — снять блокировку после аварии;
- **⛔ Сброс** — мягкий сброс контроллера (Ctrl-X);
- **обнуление** рабочих координат: XY, Z, XYZ (`G10 L20 P0`);
- **подача джога**: приложение рассчитано на принтер и шлёт 6000 мм/мин, плагин ограничивает её своей подачей
  (по умолчанию 1000 мм/мин).

Пока выбрано ЧПУ, Filum прячет всё, что есть только у 3D-принтера: нагрев, обдув, экструдер, CFS, слайсер,
таймлапсы. Скрываются и кнопки принтерных плагинов.

## Что нужно

- **Filum 0.3.0** или новее (поддержка драйверов устройств в плагинах).
- **cncd** с эндпоинтом `GET /api/status`, это
  [cnc-pi](https://github.com/fu1se/cnc-pi) после коммита «GET /api/status». Со старым cncd управление работает,
  но статус и координаты не показываются: плагин попросит обновить cncd.

## Установка

1. В Filum нажмите иконку пазла (плагины) → **По ссылке** и вставьте:
   ```
   https://raw.githubusercontent.com/fu1se/filum-cnc-pi/main/cnc-pi.js
   ```
   Или скачайте [`cnc-pi.js`](cnc-pi.js) и установите через **Из файла**.
2. Подтвердите разрешения:
   - `http` — запросы к cncd;
   - `device` — добавить тип устройства в список принтеров.
3. Меню принтеров (стрелка у названия) → **Добавить принтер** → **Тип устройства: ЧПУ (cnc-pi)**.
4. Укажите адрес cncd: `192.168.0.50:8080`. Если cncd запущен с паролем (`CNC_TOKEN`), допишите его так:
   `192.168.0.50:8080?token=пароль`.

Переключаться между принтером и станком можно в том же меню.

## Как устроено

- **Драйвер.** Плагин регистрирует драйвер через `filum.device.register()`, API описан в
  [документации Filum](https://github.com/fu1se/filum/blob/main/docs/plugins.md#devices-drivers-for-machines-other-than-klipper-printers).
- **Команды.** Действия приложения уходят в HTTP API cncd:

  | Действие | Запрос |
  |---|---|
  | джог | `POST /api/jog` |
  | Home, консоль | `POST /api/command` |
  | пауза, продолжение, стоп | `POST /api/job`, а без задания — feed hold, cycle start, сброс через `/api/realtime` |
  | файлы | `GET /api/files` |
  | запуск | `POST /api/job {action: "start"}` |
- **Опрос.** Раз в секунду плагин запрашивает `GET /api/status`. Если cncd не отвечает, опрос становится реже (до
  раза в 10 секунд), чтобы не тормозить другие плагины.
- **Свежее состояние.** Перед паузой, продолжением, стопом и запуском плагин заново запрашивает состояние: так он
  не путает идущее задание с простоем.
- **Запуск задания.** Задание запускается только в состоянии «Простой». Приложение перед запуском спрашивает
  подтверждение.

## Безопасность

- **Сброс.** «Стоп» без задания и «⛔ Сброс» — это мягкий сброс GRBL: станок встаёт мгновенно, но **теряет
  позицию**. Потом нужны `$X` и Home. Плавно остановиться можно «Паузой».
- **Задание.** Задание выполняет сама Pi. Если телефон потеряет связь, фреза продолжит работу.
- **Токен.** Он передаётся параметром `?token=` по HTTP без шифрования: не открывайте cncd в интернет.

## English

A [Filum](https://github.com/fu1se/filum) plugin that adds a GRBL CNC run by [cncd](https://github.com/fu1se/cnc-pi)
as a device you select like a printer:
- **Home tab:** status, job progress, pause / resume / stop, camera.
- **Control tab:** jog and homing, plus a CNC section with unlock, reset, work-zero buttons and jog feed.
- **Files and console:** the Files tab and the console work as usual.

**Requires** Filum 0.3.0+ and cncd with `GET /api/status`.

**Install.** In Filum go to Plugins → From URL and paste
`https://raw.githubusercontent.com/fu1se/filum-cnc-pi/main/cnc-pi.js`. Then add a printer with the device type
**ЧПУ (cnc-pi)** and the address `ip:8080`; append `?token=…` if cncd has a token. The UI texts are in Russian.
